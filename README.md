# 증바람 도우미 (Windows)

롤 **무작위 총력전: 아수라장(증바람)** 증강 선택 화면을 실시간으로 읽어서, 카드 위에 **증강 티어·예상 승률·추천 아이템**을 띄워주는 앱입니다.

통계 사이트: https://zb-stats.onrender.com

## 다운로드
**[ZBHelper.zip 받기](https://github.com/sodashi5385-maker/zb-helper/raw/main/ZBHelper.zip)** (약 54MB)

## 설치
1. 압축을 풀고 `ZBHelper` 폴더 안의 **`ZBHelper.exe`** 를 실행합니다. 설치할 것은 없습니다.
2. 처음 실행하면 Windows가 "PC 보호" 경고를 띄울 수 있습니다. 서명되지 않은 개인 제작 앱이라 그렇습니다. **추가 정보 → 실행**을 누르세요.
3. 롤은 **테두리 없는 창모드**로 해주세요. 전체 화면 모드에서는 오버레이가 가려집니다.

## 하는 일
- 게임 중 0.5초마다 화면의 증강 이름을 읽습니다. 화면은 메모리에서만 읽고 **파일로 저장하지 않습니다.**
- 롤 클라이언트에서 끝난 증바람 게임 기록을 모아 통계 서버와 공유합니다. 다른 사람에게 내려주는 데이터에서는 소환사 이름을 뺍니다. 설정에서 끌 수 있습니다.
- "다른 플레이어 게임도 수집"을 켜면 같이 게임한 사람들의 최근 증바람 전적도 천천히 받아옵니다 (게임 중엔 멈춤).

## 주의
- Riot Games와 관련 없는 팬 프로젝트입니다.
- 롤 클라이언트의 로컬 API(LCU)를 읽습니다. Riot이 공식 지원하는 방식은 아니므로 걱정되면 "다른 플레이어 게임도 수집"을 꺼두세요.
